DomainOrderRequest

  • hostname : String
    Fully-qualified domain to register or transfer (e.g. example.com).
  • type : String
    Order type.
    Enum:
    register
    transfer
  • coupon : String
    Coupon code (addDomain only).
  • whoisUnderscoreprivacy : String
    Set to \"enable\" to add Whois privacy (addDomain only).
    Enum:
    enable
    disable
